# AI Resume Screening System

## Overview

An AI-powered Resume Screening Platform built using Python, Machine Learning, NLP, and Streamlit.

## Features

- Resume Analysis
- ATS Score
- Resume Classification (ML)
- Job Recommendation
- Candidate Portal
- Recruiter Portal
- Resume Ranking
- PDF Report Generation

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- spaCy
- NLTK
- Sentence Transformers
- ReportLab
